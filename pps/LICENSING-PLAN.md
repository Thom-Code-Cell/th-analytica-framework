# PPS licensing plan

Status: **planning document — not an active licence**

## Current repository status

At the time this governance pack was prepared, the repository did not contain an umbrella software/documentation licence.

A public GitHub repository is not, by itself, a grant of unrestricted rights to copy, modify or redistribute all content. The project's intention to encourage implementation should therefore be matched by an explicit licence before broad third-party adoption.

## Target structure

The intended model is:

**Open technical layer**
- protocol specification;
- interoperability examples;
- conformance-test definitions;
- reference code that manufacturers can inspect and implement.

**Controlled trust layer**
- TH Analytica identity and branding;
- official PPS Compatible designation and badges;
- official conformance registry;
- certification/assessment services;
- governance services.

## Candidate licences for legal review

Before adoption, obtain an IP/legal review of the exact scope.

Possible candidates:

- documentation/specification: a permissive documentation licence such as Creative Commons Attribution 4.0, or a standards-oriented licence;
- reference software: a permissive software licence such as Apache License 2.0.

The choice matters because software licences may include patent grants or other conditions. **This file does not activate either licence.**

## Trademark carve-out

Any future open licence should state clearly that copyright/software permissions do not automatically grant rights to official TH Analytica trademarks, PPS compatibility badges, certification claims or endorsement.

## Contributor rights

Before accepting substantial external contributions to a Stable standard, the project should adopt a contributor policy covering:

- confirmation that contributors may submit the material;
- handling of copyright;
- disclosure of known essential patent claims where appropriate;
- permission needed to publish contributions under the project's chosen licence.

## Action required before manufacturer-scale adoption

1. complete trade-mark clearance for the intended names;
2. select and publish explicit licences;
3. review patent/licensing implications;
4. publish contribution terms;
5. launch the formal conformance registry only after tests are operational.
