# TH Analytica – Positioning Foundation (Layer 0)

Status: mandatory pre-analysis foundation for Quick Checks and Full Analyses

## Purpose

The Positioning Foundation defines what an organisation intends to be understood for before technical GEO, AEO, LLMO, AI Readiness, prompt monitoring or implementation work begins.

The framework therefore distinguishes between:

1. **intended positioning** – what the organisation wants to be known and considered for;
2. **observable positioning** – what public website and profile signals currently communicate;
3. **observed AI/search output** – what external systems actually return for controlled test questions.

These are separate evidence layers. Technical readiness must not be used as a substitute for strategic positioning.

## Mandatory fields

Every Full Analysis must document:

- **Core positioning statement:** what the organisation does and the problem/outcome it owns.
- **Primary services / offers:** the services, products or capabilities that should be associated with the entity.
- **Target audiences:** the people or organisations for whom the offer is relevant.
- **Target markets / regions / languages:** where and in which language contexts the positioning should apply.
- **Desired Query Space:** decision-relevant questions, needs and provider-selection situations in which the organisation should reasonably be considered.
- **Excluded Query Space:** topics, categories, services, geographies or claims for which the organisation should not be positioned.
- **Evidence basis:** first-party pages, references, qualifications, public records, customer evidence, operational capabilities or other verifiable support for the intended positioning.
- **Expected next action:** the appropriate user or agent action after a correct answer, for example learn more, request a quote, contact, book or purchase.
- **Confidence / evidence gaps:** what is confirmed, inferred, unknown or contradicted.

## Status model

Every analysis records exactly one Layer 0 status:

- **confirmed** – intended positioning and query space have been confirmed by the organisation or by authoritative first-party evidence.
- **inferred** – a plausible positioning can be derived from public evidence, but has not yet been confirmed.
- **open** – available evidence is insufficient to define a reliable intended positioning.
- **conflict** – public signals materially contradict the intended positioning or contradict one another.

A Full Analysis may technically continue when Layer 0 is not confirmed, but the report must keep the uncertainty visible and must not present an inferred query strategy as a confirmed business objective.

## Desired Query Space

The Desired Query Space is not a keyword list. It is a structured set of real decision situations such as:

- "Who can check our company for AI visibility in Switzerland?"
- "How do I make my website understandable for ChatGPT and Gemini?"
- "Which provider can assess Agent Readiness for a Swiss SME?"

Each query cluster should map to:

- target audience;
- problem / job to be done;
- decision stage;
- relevant service or entity;
- required evidence;
- geographic / language context;
- expected next action.

Prompt monitoring and AI-system testing must be derived from this foundation. Monitoring a large number of prompts is not useful if the prompts do not represent the organisation's intended decision space.

## Excluded Query Space

The analysis must also document where the organisation should not be positioned. This prevents accidental optimisation toward irrelevant, unsupported or misleading categories.

Examples include:

- services the organisation does not provide;
- regions it does not serve;
- qualifications it does not hold;
- regulated activities it is not authorised to perform;
- competitor categories that create semantic confusion;
- outdated offers or former business models.

## Evidence-first rule

No positioning claim receives a positive assessment merely because it appears in marketing copy. Material claims should be supported by authoritative first-party information, reproducible first-party evidence or appropriate external corroboration.

Where evidence is missing, the report should say **unverified**, **inferred** or **open** rather than filling the gap with assumptions.

## Quick Check integration

The Quick Check can only assess **observable positioning clarity** from public signals such as headings, service descriptions, entity data and calls to action.

It must not claim to know the organisation's intended positioning or Desired Query Space unless those inputs were explicitly supplied. The Quick Check therefore reports Layer 0 as a non-scored diagnostic:

- public positioning clarity;
- whether target audience / offer / region are visibly understandable;
- whether the intended query space remains unconfirmed.

## Full Analysis integration

Layer 0 appears before scored technical dimensions and before implementation recommendations.

Mandatory Full Analysis output:

1. Positioning Foundation status;
2. concise Positioning Brief;
3. Desired Query Space matrix;
4. Excluded Query Space;
5. evidence basis and gaps;
6. mapping from each major recommendation to a positioning objective or query cluster.

If a technical recommendation cannot be connected to the Positioning Foundation, it should be treated as optional maintenance rather than a strategic priority.

## Relationship to Natural Query & AI Intent

Google Search Console and other first-party demand data can validate, refine or challenge the Positioning Foundation. They do not define the business strategy on their own.

Observed natural-language queries should therefore be compared with:

- intended query clusters;
- public website answers;
- observed AI-system outputs.

This allows the analysis to distinguish demand gaps, answer gaps and semantic-positioning gaps.

## Principle

**Position first, then measure, then optimise.**

The goal is not to maximise generic AI visibility. The goal is to make the organisation understandable and verifiable in the decision contexts that actually matter, while avoiding unsupported or unwanted associations.
